# Iranian Currency & Asset Scraper <small>PHP 7.4+</small>

> A modern, resilient, and high-performance PHP library for scraping and aggregating real-time exchange rates, gold prices, coins, and cryptocurrencies.

- 🚀 **PHP 7.4 to 8.4+** Strict Compatibility
- ⚡ **High-Performance Caching & Warmup** with 0ms Lookup Latency
- 🛡️ **Resilient Multi-Layer HTML Scraping** with Fallback Profiles
- 📊 **Multi-Source Aggregation** (Average, First Available, All Sources)
- 🔍 **Global Search** by Persian Title or International Symbol
